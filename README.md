# NOIR / FORM — Fashion Store Demo

Полностью статический fashion-магазин без PHP, SQL и базы данных.

Что работает:
- главная fashion campaign;
- смена цвета hero-куртки;
- анимации товара;
- каталог и фильтры;
- сортировка;
- карточки товара;
- полноценная страница товара;
- размеры;
- wishlist;
- корзина;
- изменение количества;
- подсчёт суммы;
- localStorage;
- поиск;
- checkout demo;
- мобильная адаптация;
- выезжающее меню;
- drawers;
- переходы между разделами.

Запуск: откройте `index.html`.
